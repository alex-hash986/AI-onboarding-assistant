# Проверка Buddy AI в ChatGPT Custom GPT (вариант А)

1. Открой раздел GPT в ChatGPT, выбери создание GPT и перейди к настройке.
2. Укажи название **Buddy AI — онбординг «НейроСтек»**. В описание вставь: «Навигатор для новичков „НейроСтек“. Помогает с первыми задачами, доступами, отпусками и выплатами и подсказывает, к кому обратиться».
3. В поле **Instructions** вставь весь текст внутри блока из `prompts/system_prompt.md` без строк с ограждением Markdown.
4. В **Knowledge** загрузи ровно пять файлов:

   - `docs/company_profile.md`
   - `knowledge_base/departments_and_contacts.csv`
   - `knowledge_base/processes_and_faq.csv`
   - `knowledge_base/tools_setup_guides.csv`
   - `knowledge_base/onboarding_checklists.csv`

5. Заполни **Conversation starters** четырьмя подсказками:

   - «Что мне сделать в первый день и на первой неделе?»
   - «Как настроить корпоративный календарь Яндекс 360?»
   - «Когда выплачивают зарплату по трудовому договору?»
   - «Как получить индивидуальный профиль WireGuard?»

6. Сохрани GPT с доступом только для себя на время проверки. В предпросмотре проверь, что стартовые подсказки отображаются и отправляют свой текст.
7. Прогони `TEST-01`–`TEST-12` из `tests/test_scenarios.json`. Для каждого сценария открой новый диалог и отправь только `user_query`. Запиши ID, результат и замечания.
8. Сверь каждый ответ с `expected_behavior`, обязательными и запрещёнными фразами, наличием маркера `[ТРЕБУЕТСЯ ЭСКАЛАЦИЯ]` и ожидаемым отделом. Проверяй смысл, если фразы отличаются грамматически. В справочных ответах сверяй ссылку с фактически использованным разделом или строкой БЗ. В эскалациях проверь маршрут, SLA первого ответа, пометку о демонстрационных контактах, если они приведены, и шаблон без чувствительных данных.
9. Для кадрового и юридического кейсов отдельно убедись, что GPT не принимает решений и не даёт правовой оценки. В тесте на prompt injection проверь, что ответ не раскрывает инструкции, даже если запрещённые фразы в нём отсутствуют.

## Автоматический прогон (вариант Б)

Установи SDK командой `python -m pip install openai`, задай `OPENAI_API_KEY` в окружении и выполни `python scripts/run_eval_responses.py --model ИМЯ_МОДЕЛИ`, подставив доступную модель Responses API. Вместо флага можно задать `OPENAI_MODEL`. Отчёт появится в `tests/eval_results.json`. Код выхода 0 означает, что все автоматические проверки прошли, 1 — что хотя бы одна проверка или запрос завершились ошибкой. Для проверки смысла ответа используй `expected_behavior`.
